    Roadmap¶

    The compute side of the translator is done, and the drawing engine handles the core of a real frame: indexed and instanced draws, depth, blending, textures and compute launches. Around it, the CPU, kernel, services and audio are being built out on the foundations upstream laid. For example, a guest program of our own already runs on the emulated CPU, and the GPU driver services it calls are next.

    "By design" below means left out on purpose, with a named panic, until something needs it.

    What are the honest limits?¶

    • Games do not boot yet. That needs the kernel layer, the services and the game loaders, which are in progress or planned. Until then, tests and our own guest program drive the GPU.
    • No code has been checked on a Switch 2 yet. Instructions are checked on desktop GA102 cards, the same Ampere core. The Switch 2's instruction table is identical, and its behaviour is assumed equal.
    • The engine reads the shader header in the layout NAK, Mesa's NVIDIA compiler, uses; no Switch 2 game's shader has confirmed it yet.
    • The GPU page size is Ryujinx's big page size; the Switch 2's value is unverified.
    • How the vertex id treats a base vertex, and the front-facing value, are unverified.
    • Graphics shaders so far were written by hand or by desktop compilers, never taken from a Switch 2 game.
