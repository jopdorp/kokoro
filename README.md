<h1 align="center">oboromi</h1>
<h4 align="center">a WIP ounce emulator foundation written in Rust</h4>
<h5 align="center">written lowercase.</h5>

oboromi is an early emulator for the Nintendo Switch 2. It builds on the CPU,
service, GPU and front-end foundations laid by its maintainer and contributors.

Its own AArch64 programs now run through the loader, kernel and services. They
draw through the emulated NVIDIA Ampere GPU, play through the audio renderer and
present in the Qt window. Commercial games and firmware do not boot yet.

See the [architecture guide](https://jopdorp.github.io/oboromi/architecture/)
and [current demos](https://jopdorp.github.io/oboromi/architecture/demos/).

- **core**: core lib.
  - **audio**: renderer, effects, spatial audio and output
  - **fs**: filesystem VFS
    - probably would emulate a 32 GB UFS/eMMC to start with
  - **gpu**: Ampere SM86 GPU emulation and translation
    - SASS to SPIR-V translation
    - Vulkan compute, graphics and ray queries
  - **kernel**: system calls, handles, memory and thread scheduling
  - **nn**: high-level emulation of system services
  - **sys**: entire emulation state
  - **tests**
- **docs**
  - **sm86.pdf**: autogenerated sm86 instruction set document with nice coloured table diagrams :^)
- **guest**: small `no_std` AArch64 programs that run on the emulator
- **gui-qt**: Qt front end
- **scene**: shared command, shader and scene encoders
- **scripts**: helper and generator tools
  - **decoder_generator.rs**: generates the SM86 decoder
  - **sm_86_instructions.txt**: instruction dump, sourced from [DocumentSASS](https://github.com/0xD0GF00D/DocumentSASS).
  - **sm_86_latencies.txt**: instruction latencies as well, sourced from [DocumentSASS](https://github.com/0xD0GF00D/DocumentSASS).


## what does the name mean?

**oboromi (朧実)** is a constructed japanese neologism combining **朧 (oboro**, "hazy/vague") + **実 (-mi**, "essence/fruit").

it means **"the tangible essence of imperfection."** even if oboromi was ever finished, it could never be perfect, and that's not a failure, just what it means to be an emulator.
